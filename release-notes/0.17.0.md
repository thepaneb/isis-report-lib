## Security, AI governance and a safe text export

`0.17.0` closes two gaps that matter when reports leave the library: untrusted
payload values in diagnostics, and LLM/RAG ingestion of report content.

[![Board pack](https://thepaneb.github.io/isis-report-lib/assets/gallery/board-pack.png)](https://thepaneb.github.io/isis-report-lib/gallery/)

### Try it

```bash
pip install "isis-report-lib[xlsx]==0.17.0"
playwright install chromium
git clone https://github.com/thepaneb/isis-report-lib
cd isis-report-lib
python demo/render.py
```

Or use the container built from this release:

```bash
docker run --rm -v "$PWD:/work" ghcr.io/thepaneb/isis-report-lib:0.17.0 \
  generate demo/payload.json -o demo/out/report.pdf
```

### What changed

- **No payload values in diagnostics** — validation errors name the field/path
  and expected type; the Pydantic cause is suppressed so input values never
  reach the traceback or logs.
- **Safe text export for AI/RAG** — `render_text` / `arender_text` (and `.toon`
  variants) return a visible-only, sanitized plain-text export. Fields with
  `visible: false` are dropped; control, bidi, zero-width and private-use
  characters are stripped; and the body is wrapped in `REPORT DATA` delimiters.
- **AI governance** — `AI_USAGE.md`, CONTRIBUTING/PR-template disclosure,
  `SECURITY.md` AI-ingestion guidance, a docs security page and
  `security.txt`.
- **GHCR image** — `ghcr.io/thepaneb/isis-report-lib:0.17.0`, built from the
  release wheel with Chromium and fonts.

```python
from isis_report_lib import render_text

text = render_text(payload)  # visible-only, sanitized, REPORT DATA boundary
```

Treat the exported text as data, not instructions. The library has no AI
runtime; see [`AI_USAGE.md`](https://github.com/thepaneb/isis-report-lib/blob/main/AI_USAGE.md)
and the AI-ingestion notes in
[`SECURITY.md`](https://github.com/thepaneb/isis-report-lib/blob/main/SECURITY.md).
