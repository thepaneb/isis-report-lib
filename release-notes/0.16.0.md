## A runnable demo, a PT-BR quickstart and a hash-pinned Docker image

`0.16.0` is the demo release. One JSON payload now produces a print-ready PDF,
HTML, XLSX and CSV, with a table of contents, watermark, KPI cards, crosstab and
native Excel charts.

[![Board pack](https://thepaneb.github.io/isis-report-lib/assets/gallery/board-pack.png)](https://thepaneb.github.io/isis-report-lib/gallery/)

### Try it

```bash
pip install "isis-report-lib[xlsx]==0.16.0"
playwright install chromium
git clone https://github.com/thepaneb/isis-report-lib
cd isis-report-lib
python demo/render.py
```

Or use the container built from this release:

```bash
docker run --rm -v "$PWD:/work" ghcr.io/thepaneb/isis-report-lib:0.16.0 \
  generate demo/payload.json -o demo/out/report.pdf
```

### What's new

- **Runnable `demo/`** — a board pack with TOC, watermark, KPI cards, a table
  with totals, crosstab and native Excel charts; the same payload drives PDF,
  HTML, XLSX and CSV.
- **PT-BR quickstart** — a scoped Portuguese page at
  <https://thepaneb.github.io/isis-report-lib/pt-br/quickstart/>; the full docs
  remain in English.
- **GHCR image** — `ghcr.io/thepaneb/isis-report-lib:0.16.0`, built from the
  release wheel in the publish workflow.
- **Docker pin** — the base image is pinned by digest and the runtime is
  installed from a hash-pinned `docker/requirements.txt`.
- **Fork PR policy** — docs/config-only fork PRs get trusted empty SARIF
  analyses; code/dependency forks still need a same-repo integration branch.

### Quality

387 tests, 98.66% coverage, Python 3.11–3.15, MIT. The release artifacts include
a reproducible CycloneDX SBOM, Sigstore provenance, the wheel and the sdist.
